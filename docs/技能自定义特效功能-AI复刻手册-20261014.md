## 〇、功能定义（用户视角）

在角色技能面板的「主动技能 / 自动释放」每一行加一个「效」小按钮：

1. 点开 → egret 弹窗：左侧「收藏清单」栏（像歌单，可建多个清单），右侧特效缩略图网格（含 ◀/▶ 分页）。
2. 点格子 = 本技能指定该特效；点「随机」格 = 本技能每次施放从全池或指定清单随机抽。
3. 点格子右上角 ☆ = 收进当前目标清单；清单可建/删/改名/行内输入。
4. 「恢复默认」= 清除本技能配置。
5. 配置按**角色 id** 隔离；战斗中**只有「我」的施放**会替换特效，军团队友/他人不受影响。
6. 候选池 = 官方特效模型 1200~1599 中筛出的可用号 + 自制特效段 1600+，共 200 个（白名单制，见 data/skill-fx-selection.json）。

## 二、关键引擎事实（⚠ 不读这节必踩坑，全部是真机/e2e 实证）

1. **`WireControl.createBattleUseSkillControl` 第 1 参不是 actor 对象，是战场位置数字**。引擎调用形态：`createBattleUseSkillControl(e.position, i, t.area, t.position, t.anime1, t.anime2, t.anime3, s)`。第一版把它当 actor 判归属 ⇒ 永远判「不是我」⇒ 选了毫无效果。归属判定必须另找身份来源（见第四节）。
2. **归属唯一判据 = 战场玩家对象的 `e.isMyPlayer`**（PlayerVO/战场玩家类构造里有 `_isMyPlayer` + `setMyPlayer()`）。做法：扫 webpack 模块缓存 `req.c`，找原型**同时具备 `doUseSkill` + `calDamage`** 的战斗演算基类，包装其 `doUseSkill(e,…)`，在函数窗口内记录 `e.isMyPlayer`（finally 恢复，防泄漏）。基类可能晚于补丁加载 ⇒ `setInterval` 800ms 轮询补挂。判不出归属 ⇒ **不替换**（宁可保持原生，绝不串色）。
3. **真正渲染技能行的是模块 204 内部的局部类 E（itemRenderer），不是 RoleSkillMdr**。包 MDR 的 dataChanged 对行内按钮毫无作用；甚至挂 `eui.ItemRenderer.prototype` 基类也会被 E 自己覆盖的 dataChanged 遮蔽。**唯一可靠做法：打开技能面板后遍历舞台显示树，找到技能行实例，`Object.getPrototypeOf(row)` 反查原型再打补丁**。行特征过滤：`textSkillName + btnCheckBox + btnDel + data` 四者齐备 = 技能行。补丁标记必须用 `Object.prototype.hasOwnProperty.call(proto,…)` 自属属性判定——否则先打基类后打子类时子类继承读到标记被误跳过。
4. **本包不存在 `eui.Scroller` 滚动条皮肤**：真机实测「看不到滚动条、拖不动、选不到视口外的格子」⇒ 弹窗滚动区全部**自绘自管**：`box.mask = new egret.Rectangle(...)` 裁切 + TOUCH_BEGIN/MOVE 拖动 + mouseWheel + 右缘 5px 滚动条（可拖 thumb/可点轨）+ 页码。
5. **本包不存在 `egret.TextInput`/`eui.TextInput`**（源码无该类，构造被 try/catch 吞掉 ⇒ 清单输入框根本打不了字）。清单名输入用 **DOM `<input>` 覆盖层**：按 canvas 缩放比把 stage 坐标换算成 CSS 坐标，fixed 定位盖在弹窗上，Enter 提交 / Esc 取消。输入框与「定/消」按钮必须留 ≥16 逻辑像素间隙（v1.9.82 真机踩过 2px 间隙被设备取整盖住的坑）。
6. **dataURL 字符串不能直接赋给 `eui.Image.source`**（本机资源适配器只认资源名，dataURL 不渲染，图标区全空白）。正确链路：`base64 → new Image() → onload 里 new egret.BitmapData(img) 赋给 new egret.Texture().bitmapData → image.source = tex`。纹理异步就绪后要回调补已在台上的格子。
7. **结算特例号绝不可进候选池**：1320/1333/29998（skill-animation-patch 有专属结算节奏）；另有 mod67 残留缺资源模型 1527~1532 硬剔除；「全黑无内容」缩略图自动剔除。运行时还要**双保险**：`id>=1200 && id<=1699` 段护栏 + `resolve` 时校验号真实存在于 icons 表（防手改存档写入缺失号导致引擎加载 404）。
8. **技能 id 不能预先配置、必须按名运行时解析**：战斗链路拿到的只有技能名。用「我的 PlayerVO.skillList」建 `{name→id}` 索引（只收 type=2 回合 / type=3 主动，跳过被动），另建「去等级后缀」归一化键（`(5级)`/`(Lv5)` 等修饰）。**索引 miss ⇒ 强制重建一次再试**——装备自带技能会随穿/脱装备进出 skillList，索引可能建立于「某件装备脱着」时。改配置时置索引失效。

## 四、数据结构与解析语义

**存储**：`localStorage['worldol.skillFx']`（记账口径与 appearance-dye 一致，不进存档导出）：

```js
{ '<角色id>': {
    fx:  { '<skillId>': <特效号> | { r: 'all' | '<清单id>' } },  // 指定 | 随机来源
    fav: [特效号],                    // v1 遗留，启动时自动迁移为默认清单
    pl:  { '<清单id>': { name:'清单名(≤12字)', ids:[特效号] } },
    plNext: <number>,                // 清单 id 自增
    starTo: '<清单id>'               // 星标目标清单（显式持久化，铁律49：禁 for...in 顺序）
} }
```

**战斗解析** `resolve(myId, null, skillName)`（单一入口，patch 层只认它）：

```
skillName --normSkillName--> 索引查 skillId（miss 则重建索引再试）
skillId 无配置 ⇒ return null（不干预）
数字 n ⇒ SETTLE_EXCLUDED 拦截 + icons[n] 存在校验 ⇒ 通过返回 n
{r:'all'} ⇒ 全池随机    {r:清单id} ⇒ 清单内随机（清单空/被删 ⇒ 回退全池）
```

**优先级声明**（铁律 49）：① `__worldolSkillFx.resolve` → ② skill-animation-patch 的三特例（我们 null 时它照常）→ ③ 原生 effect。

## 五、UI 实现要点

**行内「效」按钮**：34×24 egret.Sprite（圆角底+TextField），挂到渲染器。落位锚「btnCheckBox 左侧 42px」（运行时读 `renderer.btnCheckBox.x`，皮肤改了自动跟随；行皮肤实测坐标：textSkillName x=30 / 复选框 x=433 / btnHelp x=486，唯一空档 367~433）。显隐与选中态在 `dataChanged` 里按 `this.data.type` 刷（type 2/3 显示，1 被动隐藏）；已配置特效的行底色换金色高亮。

**弹窗**（640×720，自适应小屏）：全屏遮罩（点遮罩关）+ 圆角面板 + 左清单栏(148px) + 右网格区 + 两行底部按钮（`★ 收藏到：xxx（点此切换）` / `+ 新建清单` `本技能随机来源：全池` `恢复默认`）。星标「所见即所得」：正在看某清单视图 ⇒ 星标就进那个清单；动作与显示同口径（v1.9.82 修正过「动作改 A 清单、显示却是任一清单含它」的口径分裂）。

**自管滚动区 `makeScrollArea(parent,x,y,w,h,tag)`**：返回 `{layer, setContentH, setScroll, gotoPage, scrollBy, info}`。拖动结束 `moved>8` ⇒ 180ms 内屏蔽格子点击（防拖动误选）。

**分页（v1.9.105，仅 tag==='grid'）**：
- `gotoPage(n)`：目标页钳到 `[1,pages]`，`setScroll(-(n-1)*h)` 整屏翻。
- ◀/▶ 两个 26×24 按钮钉右下角（`y=h-28`），页码标签移到按钮左侧（`x=w-116, width=48, 右对齐`）聚成分页器，`stopPropagation` 防穿透。
- **末页口径坑**：内容高不是行高整倍数时，滚动到底 `floor(-y/h)+1` 会少算一页 ⇒ 必须 `y <= -max+0.5 ⇒ page = pages` 特判。
- `pages = ceil(contentH / viewH)` 在 `setContentH` 里维护；切视图/开面板 `setScroll(0)` 回顶。
- 测试钩子链：`bridge.__uiGotoPage(n)` → `ui.testGotoPage(n)` → `gridScroll.gotoPage(n)`，e2e 断言整页偏移/越界钳末页/回退/归零。

**删除清单二次确认**：首次点「删」变「确?」3 秒内再点才删；删除后引用该清单的随机配置回退全池。

## 七、测试链与守门（照抄这套，缺了必然回归）

1. **单测** `node tools/test-skill-fx.mjs`：vm 沙箱+假 window。覆盖三种配置语义/清单 CRUD+v1 迁移/清单删除回退/结算特例与段外号禁选/按角色隔离/被动跳过+同名主动命中/旧值兼容+坏档容错。

4. **verify 守门**（verify-release-apk.mjs，新断言必须反证——对旧 APK 跑必须 FAIL 才算数）：
   - 包内 `web/skill-fx.js` 含 rev 标记与 `worldol.skillFx` 键；
   - ff bundle 含 `__worldolSkillFxPatch` + `skill-fx-switch-20261011-v2`；
   - icons 张数 = 候选池大小（⚠ 数量断言用 `.every()` 必须配 `length>=N` 防空数组假通过）；
   - entry 清单含 `web/skill-fx.js`；selection 白名单 rev/modelCount=200；
   - 号段护栏两处上限均 1699（覆盖自制段 1600+）；
   - 分页断言：包内含 `分页控件（仅网格）` 注释 + `gotoPage` + `__uiGotoPage`（v1.9.105 ①）。
   - ⚠ 版本号断言读的是**工作区 gradle**，对旧包必过——不能当反证断言；反证必须用**包内内容**断言。

## 八、分步实施清单（按序执行）

1. **扫目录**：跑 `node tools/gen-skill-fx-catalog.mjs` 产出 catalog.json + icons.js；人工过印相表把非技能号填进 `EXCLUDED_NON_SKILL`；自制特效号加进 selection 白名单。
2. **写战斗补丁** `lib/client-skill-fx-patch.mjs`（照第二节事实 1/2：位置≠actor、isMyPlayer 判归属、轮询补挂基类、判不出不替换）。
3. **写运行时主模块** `web/skill-fx.js`（存储→resolve→桥→UI 顺序写；照第二节事实 3~8）。
4. **构建接线**：第六节 3 处。
5. **单测** + `build:standalone` 后跑两条 e2e（⚠ e2e 跑的是磁盘 bundle，改 lib/web 后必须先重建）。
6. **verify 加断言**并做反证（对不含该功能的旧包必须恰好 FAIL）。
7. **真机验收**：视觉类改动必须真机确认观感再发版（铁律 4）。
8. **出包**：`node tools/release.mjs <版本> "<说明>"` → 新包 verify 全绿 + 旧包反证 → 收尾提交。

## 九、陷阱速查表（每条都真踩过）

| # | 陷阱 | 后果 | 对策 |
|---|---|---|---|
| 1 | createBattleUseSkillControl 第 1 参当 actor | 永远判「不是我」，功能全废 | doUseSkill 钩子 + e.isMyPlayer |
| 2 | 挂 eui.ItemRenderer 基类补 dataChanged | 被行类 E 覆盖遮蔽，真实行 0 按钮 | 活行实例反查原型 + hasOwnProperty 标记 |
| 3 | 用 eui.Scroller | 无皮肤：看不到条、拖不动 | makeScrollArea 全自绘 |
| 4 | egret.TextInput | 输入框打不了字 | DOM input 覆盖层 |
| 5 | dataURL 直接给 eui.Image.source | 图标区全空白 | BitmapData→Texture 异步链 |
| 6 | 结算特例 1320/1333/29998 进池 | 结算演出被破坏 | 生成器+运行时双重排除 |
| 7 | resolve 不校验号存在 | 手改存档加载 404 特效 | icons[n] 严格校验 + 段护栏 |
| 8 | 名字索引不重建 | 装备技能特效时灵时不灵 | miss 强制重建索引 |
| 9 | 分页末页 floor 公式 | 末页显示 14/15 | y<=-max+0.5 ⇒ pages 特判 |
| 10 | e2e 不真打战斗 | 归属缺陷漏测（本手册最大教训） | e2e-skill-fx-battle 断言 replaced>0 |
| 11 | 补丁内用顶层 const | toString 注入后闭包外不可见 | api 对象内联字面量 |
| 12 | for...in 决定清单顺序 | 优先级不确定 | 显式数值升序排序（铁律 49） |
| 13 | 输入框与按钮 2px 间隙 | 真机上视觉盖住 | ≥16 逻辑像素间隙 |
| 14 | e2e 改 lib/web 后不重建 | 测的是旧 bundle | 先 `build:standalone` 再测 |
| 15 | curl 走系统代理打 127.0.0.1 | 502 | `--noproxy '*'` |
