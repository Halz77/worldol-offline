# 特效管理器 + 游戏内技能改特效 · 提取包

> 提取时间：2026-10-13
> 来源：世界OL 单机版（`C:\Users\Administrator\Downloads\世界OL单机-PC版`）
> 功能边界：游戏内「技能特效自定义」面板（协议 `90038`）+ 缩略图图鉴 + 技能详情弹窗「更换特效」入口。
> 简称：下文把这套统称为 **特效管理器 / 技能改特效功能**。

---

## 1. 这是什么

把 PC 上 `tools/skill-console`（技能管理器）的「换技能特效」能力搬进游戏内的单机功能面板，
让手机版（APK）也能随时改、立刻生效、重启后还在。它与技能管理器**共用同一份补丁文件**，两边改的互相可见：

| 改动对象 | 落盘文件 | 关键 |
|---|---|---|
| 角色技能（主动/自动） | `data/skill-console.json`（键 `"id:level"`） | 写 `anime2` |
| 装备自带技能 | `data/item-skill-console.json`（键 `"itemId" → "来源:id:等级"`） | 写 `anime2` |
| 收藏清单（歌单式） | `data/skill-fx-lists.json` | 全局共享 |
| 可选特效池 | `data/skill-effect-pool.json` | 由 `tools/gen-fx-thumbs.py` 生成 |
| 缩略图 | `data/fx-thumbs/<id>.png`（181 张） | 由生成工具产出 |
| 内嵌缩略图 | `web/worldol-fx-thumbs.js`（dataURL，181 张） | 手机版靠它，外链 png 在 APK 里加载不出 |

**为什么敢在游戏里改（安全性）**：`anime2` 在 `skillBytes()` 里是定长 short，换值不改变字节长度，
技能字节 offsets、装备 `definitionBase64` 长度都不变，不存在结构性风险。但装备侧仍要求
`isItemSkillPatchable`（字节能被精确重现）才允许改，重算不了的（特殊链路生成的）一律标只读。

## 3. 三层前端分工（别混）

| 文件 | 职责 |
|---|---|
| `skill-fx-layout.js` | 纯数据：输入 (state, 视图, 滚动量, 屏幕尺寸) → 输出绝对定位元素表（rect/text/img/btn/star + 动作码）。能离线验（见 `tools/verify-fx-panel.mjs`、`preview-fx-panel.mjs`）。 |
| `skill-fx-egret.js` | 把那张元素表原样画成 Egret 显示对象，并把点击回传给面板。**拖动时只改 `scrollRect` 不重画**。 |
| `skill-fx.js` | 业务：发 90038 协议、读 snapshot、改配置、决定何时重画。 |

缩略图来源优先级：`web/worldol-fx-thumbs.js` 的 dataURL → 回退 `/fx-thumbs/<id>.png`。
手机版 eui.Image 喂外链 png 在 APK 里加载不出，所以内嵌 dataURL 是必须的。

## 4. 接线点（要复用到别的构建，必须照着改这几处）

### 4.1 服务端 `server.mjs`
- 第 47 行附近：`import {handleSkillFx,skillFxStatus} from './lib/skill-fx-service.mjs';`
- `webPaths` 注册（在 `/skill-fx.js` 之前）：
  - `/skill-fx-layout.js`、`/skill-fx-egret.js`（**顺序：layout/egret 必须排在 skill-fx.js 之前**）
  - `/skill-fx.js`、`/worldol-fx-thumbs.js`
- `/fx-thumbs/` 静态路由：命中 `^/fx-thumbs/(\d{1,6})\.png$` → 读 `data/fx-thumbs/<id>.png`
- 协议分发：把 `type===90038` 的 `Message` 交给 `handleSkillFx(...)`（与 `skillFxStatus` 一起供 `/api/status`）

### 4.2 前端 `web/index.html`
- 长行脚本区里，按此顺序引入（layout/egret 先于 skill-fx，thumbs 任意靠前）：
  `skill-fx-layout.js` → `skill-fx-egret.js` → `skill-fx.js` → `worldol-fx-thumbs.js`
- 改了 `web/*.js` 一定要把 `index.html` 里对应的 `?v=` 顶掉，否则浏览器吃旧缓存。

### 4.3 单机功能登记 `web/native-features.js`
- 第 203 行附近：面板通过 `api = {openMenu, attach, snapshot, ...}` 把自己登记进单机功能，
  手机版才会被 Egret 渲染。该 `api` 对象由本功能（skill-fx.js 的 `installSkillFx`）注入。

### 4.4 技能详情弹窗「更换特效」入口 `web/skill-fx.js`
- 第 28 行注释：入口② = `req(852) SkillDropAlertMdr` 底部「更换特效」按钮（装备技能也走这）。
- 第 556 行：`button.label='更换特效';` 即该按钮。

### 4.5 客户端随机模式运行时 `lib/client-skill-animation-patch.mjs`
- 随机模式不写 `fields.anime2`（字节层保持出厂值），由本文件的 `createBattleUseSkillControl`
  包装读 `skill-fx.js` 的 `globalThis.__worldolSkillFx.resolveForBattle` 每次施放时随机选号。
  **没有这个客户端补丁，随机模式不会生效**（固定特效不受影响，因为它靠服务端 anime2 直接下发）。

## 6. 运行期数据格式（见 `data-samples/`）

### `data/skill-console.json`（普通技能补丁）
```json
{ "version": 1,
  "skills": { "108:22": { "original": {"anime2": 1234}, "fields": {"anime2": 5678} } } }
```
- `original` 取**出厂基线**（反复打补丁不会把原值记成上一次的补丁值）；基线里没有 anime2 的条目整个字段不写。
- 写 `random` 时不写 `fields.anime2`（与固定值互斥），如 `{ "random": {"source":"all"} }`。

### `data/item-skill-console.json`（装备自带技能补丁）
```json
{ "version": 1,
  "items": { "12345": { "来源:id:等级": { "source":"...", "id":108, "level":22,
              "original":{"anime2":0}, "fields":{"anime2":9999} } } } }
```

### `data/skill-fx-lists.json`（收藏清单，歌单式，全局）
```json
{ "version": 1, "starTo": null,
  "pl": { "1": { "name": "我的收藏", "ids": [1215, 1222] } } }
```
- `starTo`：默认收藏到的清单 id（`null` = 全部特效池）。
- `pl`：清单字典，`ids` 为特效号数组。

> 这三个文件在游戏里**首次使用时自动创建**（读不到就返回空结构），不需要手工预置。
> 本包 `data-samples/` 只给**格式模板**，不含任何个人存档内容。

## 7. 改完生效的三步（缺一步就「改了等于没改」）

1. **写补丁文件** —— 持久化，重启/重进游戏仍然生效。
2. **`reloadOfficial("skill-fx-console")`** —— 内存数据恢复基线再重打补丁（含 wireBase64/layout 重算）。
3. **推 10503 + worldData** —— 让客户端当场看到新特效；**战斗中推迟**（记 pending，战斗结束补推）。

## 8. 已知边界 / 坑（承接原项目疑难）

- **被动技能（type=1）改不了特效**：`skillBytes()` 只在 `type!==1` 时写 anime1/2/3，被动技能字节里没有动画字段，
  改了下发字节一点没变 = 白改。服务端 `fxEditableOf` 用「改探针值再编码」判定，判定不能改会当场拒绝并回滚补丁。
- **装备侧只读**：`isItemSkillPatchable` 为 false 的（特殊链路生成的 35 件）一律锁只读，改了会破坏数据。
- **客户端报错先查 `logs/session.jsonl`**：`web/manager.js` 的 `reportError` → POST `/api/client-log` →
  `kind:"client", error:true` 带行号，比复现快。
- **`?v=` 必须顶**：改了 `web/*.js` 不顶版本号，玩家浏览器吃旧缓存，改了也看不到。

## 9. 与 PC「技能管理器」(`tools/skill-console`) 的关系

电脑上的 `tools/skill-console/server.mjs`（默认 8789 端口，由 `启动技能管理器.bat` 启动）是**另一套独立工具**，
功能更广（改技能数值/发技能 + 看特效库）。它和本功能的**唯一交集**是共用
`data/skill-console.json` / `data/item-skill-console.json` 两个补丁文件——PC 上改的，游戏里立刻认；反之亦然。

本提取包**只含游戏内那套（90038 面板 + 图鉴 + 更换特效入口）**。若要把 PC 技能管理器也一并提取，
它依赖 `lib/affix-editor.mjs`、`lib/equipment-skill-levels.mjs`、`lib/learned-skill-levels.mjs` 等更多模块，
需要单独再打一个包——可另行提出。

## 10. 如何把这套重新部署到一份干净的源码

1. 把 `src/lib/` 4 个文件覆盖/放入目标 `lib/`。
2. 把 `src/web/` 4 个文件覆盖/放入目标 `web/`。
3. 把 `data/skill-effect-pool.json` 与 `data/fx-thumbs/` 放入目标 `data/`（首次部署可跑 `gen-fx-thumbs.py` 重新生成）。
4. 按第 4 节改 `server.mjs` / `web/index.html` / `web/native-features.js` 三处接线。
5. 重启游戏服务（8775），`curl -s --noproxy '*' http://127.0.0.1:8775/api/status` 看 `skillFx` 段是否已出现。
