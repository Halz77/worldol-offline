## 第 54 版 · 技能编辑器（离线单文件 HTML）

需求：打包前自己改技能效果（人物技能 + 装备上的技能），HTML、不启本地服务、改完打包进游戏即生效。

### 交付
- `世界online_原版单机/技能编辑器.html`（单文件，57 KB，双击即用）
  - 载入 `data` 目录 → 搜索/筛选 → 选技能 → 选作用范围（全部/指定等级）→ 改三个效果槽
    （效果编号下拉带官方中文名、数值、附加状态下拉）+ 主动参数；勾「逐级不同值」出 22 行表格。
  - 预览用游戏自带文案（getPowerDesc 复刻）+ wire 字节数/base64。
  - 保存：「保存到 data/」直接写（浏览器支持时）否则下载 `local-skill-overrides.json`。
  - 内置使用说明对话框（含「状态标签会把效果押在减益免疫后面」这条坑）。
- `tools/build-skill-editor-data.mjs`：从 analysis 模块 4 的 POWER_*/BUFFER_* 枚举 + 主包
  getPowerDesc()/bufferText 生成内嵌标签表（221 + 33），`--check` 校验。
- `tools/skill-editor-selftest.mjs`：浏览器冒烟（Chrome headless --dump-dom），26 项 + 端到端。

### lib 改造（关键：装备技能原来改了不生效）
- `lib/local-skill-overrides.mjs`：支持 perLevel；字段白名单 OVERRIDABLE_FIELDS；
  新增 `compileOverrideRule / applyRuleToLevels / applyRuleToDefinitions / applyOverrideToDefinition(s)`。
- `lib/restoration.mjs`：`activeSkills()` 拼完 definitions（装备自带定义 + 叠加等级池）后套一次覆盖；
  `learned()` 的 importedSkillDefinitions 也套一次。
- 原因：装备技能与人技能**共用 skill id**（513 个装备技能里 301 个与 career 重叠），
  但装备路径的定义不在 skills 表里 → 必须在 activeSkills 里补第二处套用。
