- 性质：Node 服务端把「联网协议的收发」在本地实现，再配合完整 v305 H5 客户端，玩成单机。
- 两个主目录：

- 明确不用管：`世界OL字体替换工具包/`、`正式服录制工具/`（字体已替换完毕）。
