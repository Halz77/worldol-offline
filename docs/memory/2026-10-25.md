# 2026-10-25（续三）第 93 版热修：真机「效」按钮不出现（两个 bug）

## 用户反馈
进游戏打开技能面板（主动/自动/阵法三段）没有「效」按钮。

## 根因 1（首因，致命）
`web/skill-fx.js` 的 `collectSkillRows` 写了 `typeof node.numChildren !== 'function'` —— egret 的
`numChildren` 是**只读 getter（number）不是方法**，判断恒真 ⇒ 扫描第一行就 return，
从来收集不到任何技能行 ⇒ 按钮无从谈起。vm 测试当初没测「扫到行」这条路径所以漏过。
修法：按 number 取值 + 兼容方法形态。已加回归钉子用例（挂载时面板已开着也要补到按钮）。

## 根因 2（时机，会间歇出现）
`scanRows` 原来 `if(hooked) return` 早退：原型补丁只对「挂载之后新建的行」生效；
若轮询挂载发生在技能面板已打开之后，已存在的行永远不走 dataChanged ⇒ 按钮不出现。
修法：轮询常驻（800ms 幂等），每次扫描顺手给现存活行补按钮。

## 新增诊断钩子（为下次「没有按钮」类反馈准备的排查入口）
`window.__worldolSkillFxUI.status()` 一眼定位卡在哪环：stageFound / bridgeLoaded /
icons 张数 / poolSize / rowsOnStage / protoHooked / scanTimerAlive。
另加 `rescan()` 手动触发一次扫描（改完不等轮询立即验证）。
