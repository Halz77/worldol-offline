### 5. 解除魔法对幻影怪不生效（扣不了蓝）—— 本轮最有价值的一条
- **根因链**：548「解除魔法」1–21 级 `area=10`（判为单体），**22 级 `area=19`（敌全部=群体）**，
  且**只有 22 级**带效果3「燃烧最大法力值-8%」（`power3=52` `POWER_MP_PERCENT` / `value3=-8`）。
  主包 module **0251** 的 `calDamage` 里幻影判定写的是
  「**群体 且 非魔法(4) 且 非诅咒(5) 且目标有 BUFFER_HIDE(14) → 整个技能无效**」，
  而 548 的 `skillAtkType=6`（`ATKTYPE_BLESS` 祝福）正好落进这个条件。
  施放流程是 `1==calDamage(...)&&processSkillPower(...)` —— `calDamage` 返回 `!1`
  就连带效果1/2/3（含扣蓝）全部不执行。
- **修法**：**新建 `lib/client-phantom-immunity-patch.mjs`**（`phantom-skips-physical-only-v1`），
  在免疫条件里排除 `ATKTYPE_BLESS`，让幻影只免疫真正的物理群体攻击。
  祝福分支本身不产生伤害（`calDamage` 会把 DMG_DATA 全填 0、只标 `EFFECT_HIT`），
  所以不会让幻影怪被范围伤害打到。主包 +31 字节，幂等成立。
- 关键常量：`ATKTYPE_MAGIC=4 / CURSE=5 / BLESS=6`；`POWER_REMOVE_STATUS=79`、
  `POWER_MP_PERCENT=52`、`BUFFER_HIDE=14`；`getSkillAreaPlayerNum(10)` 落回 `CURSOR_1`
  （只有 19 这类才判为群体）。

## 踩坑与教训
- **`node -e` 里含中文/`${}`/正则会被 Git Bash 破坏**，一律写成 `.mjs` 脚本文件再执行。
- **`grep -o` 扫单行巨 JSON（`data/content-library.json` 等）会卡死**，改用 node 脚本解析。
- **`Add-Type`（PowerShell 编译 .NET）被安全策略拦截**，改用 `tar.exe -tf/-xf` 看/取 APK 内容。
- **PowerShell 执行策略**会拦 `.\构建APK.ps1`，要用
  `powershell.exe -ExecutionPolicy Bypass -File <绝对路径>`。
- 用 Edit 改 `server.mjs` 那条超长补丁链时**括号数写多了（15 个）**导致语法错，
  最后用脚本按 `patchOfflineLegionBattles(baseMain` 锚点重建为 14 个右括号。
  **教训：改这种超长嵌套调用，用脚本数括号比肉眼可靠。**
- 构建 APK 前必须先 `$env:NODE_OPTIONS=""; $env:CODEBUDDY_SAFE_DELETE_ENABLED="0"`
  （`cap sync` 的批量删除会被守卫拦下）。
- 本轮结束已清理：`世界online_原版单机/` 下 16 个 `.tmp-*.mjs`（含 `.tmp-test.log`）
  与 30 个 `test-*` 临时目录，均归零。
