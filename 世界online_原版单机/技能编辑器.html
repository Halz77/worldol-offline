    使用说明

    它改的是什么

    编辑器只写一个文件：data/local-skill-overrides.json（技能效果覆盖层）。它不改 career-skills.json 等抓包原始数据，而是把改动记成覆盖规则，服务端启动时套用 —— 所以既能改，又不会破坏上游验收数据。

    三种来源：人物 / 装备 / 怪物

    同一个技能 id 可能被多处使用，列表里会标出来：
    • 人物：职业/导师教的技能（career-skills.json）。
    • 装备：装备自带 / 组合技能（equipment-skill-levels.json），两件同名装备还能叠加等级。
    • 怪物：怪物 AI 放的主动与自动技能。这部分已内嵌在编辑器里，打开就能改； 其中约 200 个是怪物专属、人物学不到的技能。
    改一个技能 id，三处会一起变（它们本来共用同一份定义）。

    操作顺序

    1. （可选）载入 data 目录：选源码里的 世界online_原版单机/data 文件夹， 读入人物/装备技能表；只改怪物技能的话可以跳过这一步。
    2. 左边搜索并选中技能（可用「人物技能 / 装备技能 / 怪物技能」筛选）。
    3. 选作用范围（全部等级 / 指定等级），改 效果编号、数值、附加状态。
    4. 保存到 data/（浏览器不支持时改为下载文件，手动放进 data/ 覆盖）。
    5. 跑 安卓打包\构建APK.ps1 重新打包，进游戏即生效。

    字段含义

    • 效果编号：就是游戏里的 power。数值为负＝削减，为正＝增加。名称取自游戏自带文案。
    • 附加状态（statusBit）：和效果编号一一对应（槽1↔状态1…）。挂了减益类状态，这条效果会先过 「全减益免疫 / 状态抵抗」两道门槛 —— 打免疫怪时会被整段吃掉。想让削防等效果对免疫怪照常生效，把状态清成「无」。
    • 持续回合（round）：0 = 瞬时；大于 0 = 持续若干回合。
    • 类型：1 被动 / 2 自动 / 3 主动。被动的 wire 里不写范围、回合等字段。
    • 逐级不同值：勾上后用表格按等级逐个填，配合「指定等级」可以做出成长曲线。

    注意

    • 只覆盖 已有等级定义的技能；要新增技能请改 data/local-career-skills.json。
    • 存档里 已存在的技能定义（导入的角色）也会吃覆盖，但重新导入旧角色代码可能带回旧定义。
    • 编辑器显示的效果预览用游戏自带的文案表渲染，与游戏内技能说明一致。
